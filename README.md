# DeFiGuard: Intelligent DeFi Risk & RegTech Platform

DeFiGuard is an educational, research-oriented FinTech platform combining core decentralized finance primitives, AI-assisted transaction risk detection, RegTech compliance workflows, and smart contract static analysis.

---

## 1. Monorepo Structure

* `backend/`: FastAPI backend, SQLAlchemy 2.0 ORM, Alembic migrations, Pydantic schemas, and risk rules.
* `frontend/`: Next.js 14 App Router, TypeScript, Tailwind CSS, Lucide icons, and API client.
* `contracts/`: Educational Solidity smart contracts with Hardhat and OpenZeppelin (Phase 2 & 4).
* `ml/`: Anomaly detection pipeline (Isolation Forest) and feature extraction modules (Phase 3).
* `docs/`: Technical specifications, architecture blueprints, and threat models.

---

## 2. Prerequisites

* **Python:** 3.10+
* **Node.js:** 18+ (tested on Node v24.16.0)
* **npm:** 9+ (tested on npm 11.13.0)

## 3. Quick Start & Run Commands

### 3.1 Backend Setup

```bash
cd backend

# Create virtual environment (if not already created)
python -m venv .venv

# Activate virtual environment
# On Windows (PowerShell):
.venv\Scripts\Activate.ps1
# On Linux/macOS:
source .venv/bin/activate

# Install dependencies
pip install -r requirements.txt

# Run database migrations
alembic upgrade head

# Start FastAPI development server
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

* API Docs (Swagger): [http://localhost:8000/docs](http://localhost:8000/docs)
* Health Check: [http://localhost:8000/health](http://localhost:8000/health)

### 3.2 Frontend Setup

```bash
cd frontend

# Install dependencies
npm install

# Start Next.js development server
npm run dev
```

* Frontend UI: [http://localhost:3000](http://localhost:3000)

### 3.3 Running Automated Tests

```bash
cd backend
.venv\Scripts\pytest -v
```
